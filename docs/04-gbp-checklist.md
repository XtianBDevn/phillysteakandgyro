# Google Business Profile — Audit & Action Checklist

For a single-location restaurant, **GBP drives more traffic than the website itself.** This is the highest-leverage hour of work in the whole engagement.

## Audit (do once)

- [ ] Listing exists and is **claimed** by the owner (not a previous owner or random aggregator).
- [ ] Business name is exactly `Philly Steak & Gyros` (no keyword stuffing — Google penalizes).
- [ ] **Primary category:** Cheesesteak restaurant.
- [ ] **Secondary categories:** Greek restaurant · Mediterranean restaurant · Wings restaurant · Sandwich shop.
- [ ] Address pin is **exactly on the storefront** (open the listing on mobile and walk to it if needed).
- [ ] Hours match the website. Set holiday hours for the next 12 months.
- [ ] Phone number matches the website exactly (NAP consistency).
- [ ] Website link points to root domain with `https://`.
- [ ] Menu link points to `/menu` page.
- [ ] Order link is enabled (DoorDash / Uber Eats via "Food ordering" attribute).
- [ ] At least **20 owner-uploaded photos** in these buckets: exterior, interior, food close-ups, team.
- [ ] At least **5 videos** under 30s each.
- [ ] Attributes set: dine-in · takeout · delivery · curbside (if true) · vegetarian options · accepts credit cards.

## Weekly cadence (15 min/week)

- [ ] 1 Google Post (offer, event, or new menu item).
- [ ] Reply to every new review within 48 hours.
- [ ] Answer any new Q&A within 48 hours.
- [ ] Upload 2-3 fresh photos.

## Monthly review

- [ ] Pull Insights → impressions, calls, direction requests, website clicks. Track in spreadsheet.
- [ ] Audit competitor listings within 1 mile for category/attribute drift.
- [ ] Re-take 3 dish photos for visual freshness.

## Review-flywheel setup

- [ ] Print a small **QR-to-review** card next to the register, 5×7 size, friendly copy.
- [ ] At pickup, server hands the bag with: *"If we did good, would you mind sharing on Google?"*
- [ ] Optional automation (Tier-2 upsell): post-order SMS via Twilio with the GBP review link 90 min after pickup.

## Red flags to monitor

- Any review under 3 stars → owner gets a push notification, responds same day.
- Sudden spike in 1-star reviews → competitor sabotage; report to Google.
- Hours change in Google's auto-suggested edits → reject if wrong.
